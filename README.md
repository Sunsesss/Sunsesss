# СКТБ «СКиТ»

Адаптивный сайт компании по утверждённому визуальному концепту. Vite, JavaScript, локальный шрифт Manrope и Phosphor Icons. Фотографии поставлены пользователем; предметная композиция подготовлена по ним для первого экрана.

## Посмотреть без установки программ

Скачайте [`downloads/skit-offline.zip`](downloads/skit-offline.zip), распакуйте архив и откройте вложенный `index.html` двойным щелчком. Это автономная версия: CSS, JavaScript, шрифты, изображения и иконки встроены в один HTML. Сервер и интернет не требуются. Контактные ссылки открывают почтовую программу.

Корневой `index.html` этого репозитория является **исходником для Vite**: для него нужен запуск через `npm run dev`, а не через Python. Для обычного статического хостинга используйте сборку `dist` или `downloads/skit-ready.zip`.

Чтобы заново создать автономный HTML из исходников:

```sh
npm ci
npm run build:portable
```

Результат находится в `portable/index.html`.

## Блок КНС с 3D

После направлений размещён блок «Мощность. Под вашим контролем». Прокрутка вращает настоящую объёмную модель Three.js и последовательно показывает четыре группы характеристик. Кнопки 01–04 переключают этапы без необходимости прокручивать вручную.

Модель — визуальная реконструкция по фотографиям, не инженерная CAD-модель. Она содержит объёмные платы, панель, конденсаторы, трансформатор, катушки, радиаторы и разъёмы. Надписи с обозначением «1500…» удалены с текстур модели. Числовые характеристики относятся к подтверждённому пользователем верхнему правому исполнению на слайде: вход 95–265 В, 50–60 Гц, коэффициент мощности 0,99; выход 3–33 В DC и до 53 А; КПД ≥93%, пульсации до 40 мВ; −50…+50 °C; до 1500 Вт с принудительным и до 1000 Вт с конвекционным охлаждением.

Для объёмного вращения нужен WebGL2. Если он недоступен, сохраняются изображение модели и все характеристики. Учтена системная настройка уменьшения движения: без закрепления экрана при прокрутке, с переключением этапов кнопками. Рендер запускается только рядом с блоком, при изменении ракурса и останавливается после завершения движения. Все текстуры, код Three.js и изображения встроены в автономную версию; CDN не используется.

## Запуск

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

## Сборка

```sh
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

В `dist/` создаётся статический сайт для публикации. Внешние API и секреты не требуются. Все шрифты и изображения размещены локально. Контактная почта: mail@skitlab.ru. Кнопки связи открывают почтовую программу; отправки через сервер нет.

Направления раскрываются на главной; меню поддерживает клавиатуру и Escape. Производственная галерея переключает три фотографии. Учтена настройка уменьшения движения. Контакты и реквизиты взяты из предоставленной презентации, почта обновлена по указанию пользователя.
