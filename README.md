# СКТБ «СКиТ»

Сайт компании: Vite, JavaScript, Three.js, локальные Manrope и Phosphor Icons. Реальные фотографии предоставлены пользователем. На первом экране используется исходный снимок планшета без нейрогенерации; изображение в разделе разработки сохранено по пожеланию пользователя.

## Две версии

- **Для просмотра:** [skit-offline.zip](https://github.com/Sunsesss/Sunsesss/blob/setup/cloud-environment/downloads/skit-offline.zip). Распакуйте и откройте `index.html` в браузере. Всё встроено в один HTML; установка Python или Node.js не нужна.
- **Для разработки:** [skit-project.zip](https://github.com/Sunsesss/Sunsesss/blob/setup/cloud-environment/downloads/skit-project.zip). Исходники, модель GLB, редактируемый Blender-проект, скрипты сборки и документация.

Корневой `index.html` проекта — исходник для Vite. Его нужно запускать командой ниже. Для обычного статического хостинга предназначены папка `dist/` или `downloads/skit-ready.zip`.

На телефоне файл нужно открыть именно в браузере: просмотрщики вложений и приложение «Файлы» могут ограничивать JavaScript/WebGL. Для проверки мобильного сайта в обычных условиях используйте проект на HTTP(S)-адресе. Даже без JavaScript остаются доступными нативное открытие/закрытие меню, разделы продукции, все характеристики и контактные ссылки.

## Запуск проекта

Нужен Node.js 20.19+ (рекомендуется актуальная LTS-версия).

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

Откройте `http://localhost:4173`. Для телефона в той же сети можно использовать сетевой адрес, который Vite напечатает в терминале; доступ зависит от локального брандмауэра.

## Сборка

```sh
npm run build
npm run preview -- --host 0.0.0.0 --port 4173 --strictPort
```

Результат `dist/` можно разместить на статическом хостинге. Внешние API, секреты и CDN не нужны. Кнопки связи открывают почтовую программу или приложение звонков; серверной отправки форм нет. Почта: **mail@skitlab.ru**.

## Автономный файл

```sh
npm run build:portable
```

Результат — `portable/index.html`. Стили, WOFF2-шрифты, фотографии, GLB-модель и скрипты встроены внутрь. Используется обычный JavaScript без внешних модулей. Старые копии SVG/TTF/WOFF-шрифтов в эту версию не включаются. Автономная версия содержит те же меню и анимации, что и проект.

Готовые ZIP-архивы формируются после сборки командой `python scripts/pack-delivery.py`. Python нужен только для упаковки, не для просмотра автономной версии или сборки сайта.

## Навигация и движение

- Нативное полноэкранное меню с крупными разделами и контактами. JavaScript добавляет закрытие по Escape, возврат фокуса, ограничение фокуса внутри меню и закрытие при переходе.
- Построчное появление заголовка, вход фотографий, появление разделов при прокрутке, переходы галереи, состояния наведения и индикатор чтения. Основной контент виден и без анимаций; для анимаций входа предусмотрено принудительное завершение при задержке графического таймлайна.
- Учитывается `prefers-reduced-motion`: без плавных перемещений, появления элементов и закреплённой истории КНС.
- Направления продукции и полная таблица параметров — обычный HTML, доступный без JavaScript.

## Модель КНС

После направлений — блок «Мощность. Под вашим контролем». Прокрутка поворачивает модель; кнопки 01–04 переключают этапы. Метки и линии привязаны к точкам объёмной модели. Добавлены освещение, отражения, тени и запасное изображение для устройств без WebGL2.

- `model/kns.blend` — редактируемая модель Blender с упакованными ресурсами.
- `public/assets/kns.glb` — оптимизированная веб-модель без внешних текстур и декодеров.
- `scripts/build-kns.py` — воспроизводимая сборка геометрии: фаски, отверстия, крепёж, разъёмы, обмотки, полупроводники и объёмные подписи индикаторов.
- `scripts/optimize-kns.mjs` — объединение/квантование и сжатие текстур для браузера.
- `model/reference/` — исходные материалы и лицензия шрифта для физических надписей.

Для пересборки модели нужен Blender 4.3+ в PATH:

```sh
npm run model:build
npm run build:portable
```

Модель — визуальная реконструкция по фотографиям с приблизительными размерами и деталями; для инженерного применения нужен исходный CAD. Надпись «1500…» на самой модели отсутствует. Рендер запускается рядом с блоком и останавливается после завершения движения или ухода блока с экрана; плотность пикселей ограничена на телефонах.

Числовые параметры относятся к подтверждённому пользователем верхнему правому исполнению на слайде: вход 95–265 В, 50–60 Гц, коэффициент мощности 0,99; выход 3–33 В DC и до 53 А; КПД ≥93%, пульсации ≤40 мВ; −50…+50 °C; до 1500 Вт с принудительным / 1000 Вт с конвекционным охлаждением.

## Проверки

Сборка: `npm run build`. Браузерный скрипт `scripts/check-site.py` требует отдельно установленный Python Playwright и Chromium:

```sh
python -m pip install playwright
python -m playwright install chromium
python scripts/check-site.py
```

По умолчанию проверяется сайт на порту 4173. Переменные `SKIT_TEST_URL`, `SKIT_CHROMIUM_PATH`, `SKIT_QA_DIR` и `SKIT_TEST_OFFLINE=1` позволяют выбрать другой адрес, браузер, папку доказательств или проверку автономного HTML с блокировкой внешних запросов. Итоговые результаты и ограничения проверки описаны в `design-qa.md`. Настоящее устройство пользователя и iOS/WebKit не выдаются за проверенные одной эмуляцией размеров в Chromium.
